# The claim flow (/claim, /verify, /confirmation, /upload-form) is kept out of
# the index by "noindex" in each page's <head>, NOT by Disallow. A robots.txt
# Disallow would stop crawlers fetching those pages at all, so they could never
# read the noindex — and Google can still list a blocked URL it finds via links.
# Blocking and noindexing the same page works against itself; noindex alone is
# what actually removes them. Do not re-add Disallow lines for those paths.
#
# Also note robots.txt rules are PREFIX matches: "Disallow: /claim" would match
# /claim-super-leaving-australia too. That trap is why the paths above are
# handled with noindex instead.
